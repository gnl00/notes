# MySQL 配置详解

## 配置查看

```sql
-- 查看单个参数
show variables like 'max_connections';

-- 查看一组参数
show variables like 'innodb%';

-- 查看运行时状态
show global status like 'Threads%';
```

## 常用配置项

### 连接与线程

- `max_connections`：最大连接数。
- `wait_timeout` / `interactive_timeout`：空闲连接超时。
- `thread_cache_size`：线程缓存，减少线程频繁创建销毁。

### 内存与 InnoDB

- `innodb_buffer_pool_size`：最关键内存参数，生产环境通常占机器内存的大头。
- `innodb_buffer_pool_instances`：Buffer Pool 分片数量（大内存场景可考虑）。
- `innodb_log_buffer_size`：大事务场景可适当增大。
- `tmp_table_size` / `max_heap_table_size`：控制内存临时表上限。

### 持久化与日志

- `innodb_flush_log_at_trx_commit`：事务提交持久化策略（0/1/2）。
- `sync_binlog`：binlog 刷盘策略。
- `log_bin`：是否开启 binlog。
- `slow_query_log` / `long_query_time`：慢查询日志与阈值。

### 复制相关

- `server_id`：复制节点唯一 ID。
- `read_only` / `super_read_only`：只读控制（从库常用）。
- `binlog_format`：`ROW` / `STATEMENT` / `MIXED`（推荐 `ROW`）。

### 字符集

- `character_set_server`：建议 `utf8mb4`。
- `collation_server`：与字符集匹配（如 `utf8mb4_0900_ai_ci` 或业务指定排序规则）。

## 5.7 与 8.0 常见差异

- 隔离级别变量：8.0 推荐 `transaction_isolation`，5.7 常见 `tx_isolation`。
- 复制术语：8.0 更推荐 `source/replica`，5.7 常见 `master/slave`。
- 数据字典：8.0 不再使用 `.frm`。

## 调优建议

1. 先确定目标：吞吐、延迟、成本、稳定性优先级。
2. 先观测再修改：结合 `show status`、慢日志、`EXPLAIN ANALYZE`。
3. 单参数小步变更：每次只改 1-2 个关键参数并做压测对比。
4. 区分环境：开发、测试、生产不要共用同一套参数。
5. 保守上线：高峰期避免大范围参数调整。
